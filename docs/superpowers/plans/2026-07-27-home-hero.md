# Home Hero Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Substituir o bloco introdutório da home por um hero full-bleed atmosférico teal, com a lista de provas imediatamente abaixo.

**Architecture:** CSS do hero em `globals.css` (fundo, grain, animações). Markup e copy em `src/app/page.tsx`, com breakout do `main.container` via full-bleed. Lista de provas permanece na mesma página com `id="provas"`.

**Tech Stack:** Next.js App Router, React 19, Tailwind 4, CSS variables existentes (Fraunces / Source Sans).

## Global Constraints

- Spec: `docs/superpowers/specs/2026-07-27-home-hero-design.md`
- Marca hero-level: Treino Concursos
- Copy fixa do spec (headline, apoio, CTAs)
- Sem cards/stats/badges no hero
- Mobile-first; horizontal só a partir de `lg` se necessário
- Sem em/en dashes; PT-BR

## File map

| File | Role |

| `src/app/globals.css` | `.home-hero`, grain, keyframes |
